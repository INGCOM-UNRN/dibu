# Sistemas digitales

Álgebra de Boole, tablas de verdad, mapas de Karnaugh y circuitos con compuertas.

| Tipo | Diagrama | Para qué |
| :--- | :--- | :--- |
| [`truth_table`](truth_table.md) | Tabla de verdad | Tablas de verdad de una o varias funciones, con columnas intermedias y formas canónicas. |
| [`karnaugh`](karnaugh.md) | Mapa de Karnaugh | Mapas de 2 a 4 variables con los agrupamientos mínimos y la expresión simplificada. |
| [`logic_circuit`](logic_circuit.md) | Circuito lógico | El circuito con compuertas que implementa una expresión booleana. |
