# Estructuras lineales

Arreglos, matrices, listas enlazadas, pilas y colas, con sus direcciones de memoria.

| Tipo | Diagrama | Para qué |
| :--- | :--- | :--- |
| [`array`](array.md) | Arreglo | Arreglos en memoria, con índices, direcciones, offsets y punteros que los recorren, y secuencias de Python con sus cortes. |
| [`matrix`](matrix.md) | Matriz | Matrices estáticas, dinámicas, dentadas, planas y de Java, como están en memoria. |
| [`linked_list`](linked_list.md) | Lista enlazada | Listas simples, dobles y circulares, con direcciones, cursores y estructura cabecera. |
| [`stack`](stack.md) | Pila | Pilas en arreglo, con el tope, y su evolución paso a paso. |
| [`queue`](queue.md) | Cola | Colas lineales y circulares, con frente y final. |
