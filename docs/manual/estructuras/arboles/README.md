# Árboles y tablas

Árboles binarios y de búsqueda, montículos, AVL con sus rotaciones, árboles B+ y tablas de hash.

| Tipo | Diagrama | Para qué |
| :--- | :--- | :--- |
| [`tree`](tree.md) | Árbol binario | Árboles binarios, de búsqueda, AVL y montículos, por niveles, por inserciones o anidados. |
| [`heap`](heap.md) | Montículo (heap) | Min-heaps y max-heaps construidos por inserciones o con heapify, con sus operaciones. |
| [`avl`](avl.md) | Árbol AVL | Inserciones y eliminaciones en un AVL, con las rotaciones que hace cada una. |
| [`bplus_tree`](bplus_tree.md) | Árbol B+ | Inserciones en un árbol B+, con las divisiones de hojas y nodos internos. |
| [`hash_table`](hash_table.md) | Tabla de hash | Inserciones en una tabla de hash, con encadenamiento o direccionamiento abierto. |
