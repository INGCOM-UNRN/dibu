# Análisis de algoritmos

Complejidad, diagramas de flujo, costos línea por línea, pruebas de escritorio, programación dinámica y caminos mínimos.

| Tipo | Diagrama | Para qué |
| :--- | :--- | :--- |
| [`complexity`](complexity.md) | Complejidad | Curvas de crecimiento para comparar órdenes, y jerarquías de clases de complejidad. |
| [`flowchart`](flowchart.md) | Diagrama de flujo | Diagramas de flujo armados a partir de la estructura del algoritmo. |
| [`cost_table`](cost_table.md) | Tabla de costos | El análisis de un algoritmo línea por línea, con el costo y las veces de cada una. |
| [`trace_table`](trace_table.md) | Tabla de traza | Pruebas de escritorio de variables y trazas de operaciones sobre una estructura. |
| [`dp_table`](dp_table.md) | Tabla de programación dinámica | LCS, distancia de edición, mochila 0/1 y cambio de monedas, con el camino de reconstrucción. |
| [`dijkstra`](dijkstra.md) | Dijkstra | La tabla de iteraciones del algoritmo de Dijkstra y los caminos mínimos. |
